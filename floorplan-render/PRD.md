# 户型图 AI 生成装修效果图 - 产品需求文档

## 1. 产品概述

一款基于 AI 的装修效果图生成工具，用户可上传户型图（支持 PDF、CAD、图片格式），系统自动解析并生成多种装修风格的效果图。帮助设计师、业主快速预览装修效果，提升沟通效率。

核心价值：
- 支持多种户型图格式上传与智能解析
- AI 生成多种装修风格效果图
- 3D 房间预览功能
- 快速迭代设计方案

## 2. 目标用户

| 用户类型 | 使用场景 | 核心需求 |
|---------|---------|----------|
| 业主 | 装修前预览效果 | 快速获取效果图，比较不同风格 |
| 设计师 | 方案沟通与提案 | 高效生成效果图，减少修改周期 |
| 装修公司 | 获客展示 | 提供可视化方案，提升签单率 |
| 学生 | 学习室内设计 | 了解不同装修风格效果 |

## 3. 核心功能

### 3.1 文件上传与解析

**支持格式**：
| 格式 | 处理方式 | 说明 |
|------|----------|------|
| JPG | 直接压缩 | 转为 PNG，最大边 1024px |
| PNG | 直接压缩 | 最大边 1024px |
| PDF | pdf2image 转换 | 提取第一页，可选页码 |
| DXF | ezdxf 解析 | 提取几何数据渲染为 PNG |
| DWG | 不支持 | 提示用户转换为 DXF |

**解析结果展示**：
- 原始尺寸（像素）
- 比例估算
- 房间数量检测（基于图像分析）
- 预览缩略图

### 3.2 装修风格选择

| 风格 | 英文标识 | 风格描述 |
|------|----------|----------|
| 现代简约 | modern-minimalist | Clean lines, neutral colors, functional furniture |
| 北欧风 | nordic | Light woods, white tones, cozy textiles |
| 新中式 | chinese-modern | Traditional elements, elegant wood, muted colors |
| 轻奢风 | light-luxury | Gold accents, marble textures, sophisticated lighting |
| 工业风 | industrial | Exposed bricks, metal fixtures, raw aesthetics |
| 日式风 | japanese | Warm wood, tatami mats, minimalist Zen atmosphere |

### 3.3 效果图生成

**Prompt 模板**：
```
Professional interior design rendering based on architectural floor plan,
[风格英文描述], spatial layout preserved, furniture placement,
natural lighting, photorealistic, 4k, architectural visualization
```

**生成流程**：
1. 用户选择风格
2. 提交生成任务
3. 异步处理（轮询状态）
4. 返回效果图 URL

### 3.4 3D 预览功能

- Three.js 简单房间盒子
- ExtrudeGeometry 墙体（高度 2.8m）
- 地面贴效果图纹理
- OrbitControls 旋转/平移/缩放
- Ambient + Directional 光照

### 3.5 下载功能

- 效果图原图下载
- 3D 场景截图（PNG）

## 4. 用户界面设计

### 4.1 设计风格

- **主题风格**: 建筑美学 + 科技感的现代工具风格
- **色彩方案**:
  - 主色调: #1A1A2E (深蓝黑) - 专业稳重
  - 辅色调: #16213E (深蓝) - 层次分明
  - 强调色: #E94560 (珊瑚红) - CTA 按钮
  - 辅助色: #0F3460 (藏蓝) - 卡片背景
  - 文字色: #EAEAEA (浅灰白)
- **按钮风格**: 圆角矩形，悬停微光效果
- **字体选择**:
  - 标题: Outfit (Google Fonts) - 现代几何感
  - 正文: Inter - 清晰易读
- **布局风格**: 卡片式布局，分栏对比设计

### 4.3 组件设计

| 组件 | 功能描述 | 样式特点 |
|------|----------|----------|
| UploadZone | 文件拖拽上传 | 虚线边框，悬停高亮，文件类型图标 |
| FilePreview | 解析后预览 | 缩略图 + 文件信息卡片 |
| StyleSelector | 风格单选 | 圆形图标 + 风格名称 + 选中态 |
| CompareView | 左右对比 | 可拖动分割线，原图/效果图切换 |
| RenderResult | 效果图展示 | 响应式网格，支持灯箱 |
| 3DViewer | Three.js 3D 预览 | 轨道控制器，地面纹理 |
| ProgressIndicator | 生成进度 | 步骤条 + 百分比 + 状态文字 |
| DownloadButton | 下载按钮 | 主色按钮 + 下载图标 |

## 5. 数据统计指标

| 指标 | 描述 |
|------|------|
| 上传成功率 | 成功解析文件数 / 上传文件数 |
| 生成成功率 | 成功生成效果图数 / 生成请求数 |
| 平均生成时间 | 从提交到完成的平均耗时 |
| 用户满意度 | 用户反馈评分 |

## 6. 非功能性需求

### 6.1 性能要求

- 文件上传: 支持最大 50MB
- 图片处理: 单次处理不超过 30 秒
- 效果图文生图: 单次生成 10-30 秒

### 6.2 安全要求

- 文件类型白名单校验
- 上传文件大小限制
- API 密钥环境变量管理

### 6.3 可用性要求

- 上传进度实时显示
- 生成状态轮询更新
- 错误提示友好明确
